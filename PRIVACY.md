# Privacy

This repository is designed for local execution.

## Data handled during a run

The browser workflow may temporarily observe note IDs, album IDs, titles, URLs, dates, and visible account state. Store only what is necessary to prepare and verify the plan.

## Data that stays local

Runtime inventories, plans, checkpoints, screenshots, browser profiles, and logs belong under `.xhs-organizer/` or another excluded local directory. They must not be committed.

## Login data

The user logs in directly in the dedicated browser. The workflow must not ask the user to paste a password, cookie, token, or browser storage export into chat or a plan file.

## Public examples

All IDs and titles under `examples/` are synthetic. The case study describes workflow lessons without publishing account identifiers or deleted content.
